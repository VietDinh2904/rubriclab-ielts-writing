# RubricLab IELTS Writing

A browser-based IELTS Writing learning space with:

- Academic Task 1 and Task 2 prompt libraries
- IELTS rubric scoring and spider-chart feedback
- Inline sentence highlights and revision comments
- Band-based vocabulary and collocation library
- Interactive practice activities

Live app: https://rubriclab-writing.hailx.chatgpt.site

## Run locally

Open `dist/index.html` through any static web server.
